# Версия 1.0.1

Музыка: добавлена композиция «Foxglove Workshop» как зацикленная фоновая
тема вместо временной процедурной мелодии. Громкость регулируется существующим
ползунком музыки в настройках.

Исправления: автоматическое размещение основных панелей по размеру содержимого,
масштабирование слишком больших меню, сохранение пропорций 16:9 при изменении окна,
подбор окна под рабочую область монитора, F11 для полного экрана, устранение
перекрытий точек осмотра информационной панелью, корректное обновление подсказок
при быстрых нажатиях. Сохранения записываются через временный файл; предыдущий
корректный файл сохраняется как .bak и используется при ошибке чтения основного.

Проверки: tests/smoke_test.gd проходит все пять проектов, навыки, события,
финал и повторное прохождение без двойных наград. tests/release_audit.gd
проверяет основные меню, пять экранов осмотра, три варианта выбора, паузу,
настройки, запись/чтение сохранений и восстановление резервной копии.
В графическом режиме проверяются окна 960×540, 1024×768, 1600×900 и 900×900.
Контрольные изображения находятся в preview/audit_*.png и не входят в сборку.

Ограничения проверки: один компьютер Windows с NVIDIA GTX 1060; нет проверки
на других GPU, на нескольких мониторах и с разными масштабами Windows DPI.
Это исправленная сборка существующей короткой кампании, а не гарантия
отсутствия ошибок во всех возможных последовательностях действий.

Следующие улучшения: сохранение текущего шага незавершённого задания,
несколько слотов сохранения, настройка размера текста, журнал реплик,
профилирование загрузки и памяти на слабых компьютерах. Сейчас сохраняется
прогресс компании, но не точная позиция внутри диалога/осмотра.
