## Запуск

Готовые сборки не хранятся в Git. Скрипт `build_release.ps1` создаёт версию Windows в `build/v1_3/`, архив для Яндекс Игр и отдельный архив для Netlify в `build/`. Для сборки нужны Godot 4.7.1 и соответствующие шаблоны экспорта; путь к Godot можно передать параметром скрипта.

Для разработки откройте `project.godot` в Godot 4 и нажмите F6/F5.

Рекомендуемое разрешение — 1280×720 или выше.
